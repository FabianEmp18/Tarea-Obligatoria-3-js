# Tarea 3 - Calculadora en JavaScript

## Descripción

En esta actividad se realizó una calculadora utilizando un objeto en JavaScript. El programa permite elegir diferentes operaciones matemáticas mediante un menú que aparece en la terminal.

Los números son ingresados por el usuario y, después de mostrar el resultado, el programa vuelve al menú para realizar otra operación o salir.

## Operaciones disponibles

1. Sumar
2. Restar
3. Multiplicar
4. Dividir
5. Potencia al cuadrado
6. Raíz cuadrada
7. Salir

## Funcionamiento

La calculadora utiliza un objeto que contiene las propiedades para guardar los números ingresados y los métodos para realizar cada operación.

También se utilizó `readline` para permitir el ingreso de datos desde la terminal de Node.js.

El programa incluye algunas validaciones, como evitar la división por cero, controlar los números ingresados y mostrar un mensaje cuando se selecciona una opción incorrecta.

## Cómo ejecutar el programa

Para probarlo, es necesario tener instalado Node.js.

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir la terminal.
3. Ejecutar el siguiente comando:

```bash
node tarea3.js
```

4. Elegir una opción del menú e ingresar los números solicitados.

## Tecnologías utilizadas

- JavaScript
- Node.js
- Visual Studio Code
